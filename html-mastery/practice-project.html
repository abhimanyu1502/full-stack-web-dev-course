45. Practice Project

It's time to put everything together. Build a complete webpage from scratch.

🌐 <head> & <body> Project: Complete <head> & <body>
Tag Placement: Your practice project includes assembling a complete valid HTML document with both the metadata <head> tag and the rich semantic <body> tag.
🎯
Task: Build Your Personal Profile Page

Create a file named index.html. Build a webpage containing the following elements in order:

  1. A Header with a Main heading and Navigation (Home, About, Skills, Contact)
  2. An About section using <section>
  3. An "About Me" paragraph
  4. A Profile image (with alt text)
  5. A Skills list (Unordered list)
  6. Five hobbies (Unordered list)
  7. A Daily routine (Ordered list)
  8. An Education table
  9. A Contact form containing:
    • Name, Email, Date input
    • Gender radio buttons inside a fieldset
    • Skills checkboxes
    • City dropdown
    • Message textarea
    • Submit button
  10. A Footer

Rules: Use semantic HTML, accessible labels, and proper heading hierarchy.
