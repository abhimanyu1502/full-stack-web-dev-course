34. Global Attributes

Global attributes are attributes that can be used on almost any HTML element.

👁️ <body> Used on <body> tags
Tag Placement: Global attributes (like title, tabindex, hidden, contenteditable) can appear on almost any element, predominantly on visible tags in the <body> tag.

Code Example

HTML 
<div id="my-div" class="box"></div>

<p title="This is a tooltip">Hover over me</p>

<span hidden>You can't see me</span>

<div tabindex="0">I can be focused with the keyboard</div>

<p contenteditable="true">You can edit this text!</p>

<div draggable="true">Drag me</div>

Explanation of the Code

  • id and class: For CSS and JS targeting.
  • title: Shows a tooltip on hover.
  • hidden: Hides the element entirely from the screen and screen readers.
  • tabindex: Controls whether an element can receive keyboard focus.
  • contenteditable: Allows the user to edit the text directly in the browser.
  • draggable: Specifies whether an element is draggable (used with Drag and Drop API).
