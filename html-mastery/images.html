10. Images

Images can make a webpage much more engaging. In HTML, the <img> element is used to embed images. It is an empty element, meaning it has no closing tag.

👁️ <body> Used under tag
Tag Placement: The <img> tag is placed inside the <body> tag to display visible pictures and illustrations on the page canvas.

Syntax

HTML 
<img src="path/to/image.jpg" alt="Description">

Code Example

HTML 
<!-- Standard Image -->
<img
    src="mountain.jpg"
    alt="Snow-covered mountain at sunrise"
    width="800"
    height="500"
>

<!-- Decorative Image -->
<img src="decoration.svg" alt="">

Explanation of the Code

  • src (Source): The path to the image file. This can be a local file path or a full URL.
  • alt (Alternative Text): Describes the image. This is read by screen readers for visually impaired users, and displays if the image fails to load.
  • width and height: Specify the dimensions in pixels. Adding these prevents "layout shift" as the image loads.
  • For purely decorative images (like abstract background shapes), use an empty alt attribute (alt="") so screen readers ignore it.
