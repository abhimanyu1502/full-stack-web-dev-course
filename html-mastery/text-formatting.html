7. Text Formatting & Semantic Text Elements

HTML provides semantic tags specifically designed to give contextual meaning and styling to inline text. Unlike generic CSS formatting, these tags convey importance, emphasis, citations, deletions, or mathematical notations to browsers, screen readers, and search engines.

While browsers render tags like <strong> as bold and <em> as italic, their primary purpose in modern HTML5 is semantic meaning rather than purely visual presentation.

👁️ <body> Used under tag
Tag Placement: Inline text-formatting tags (<strong>, <em>, <mark>, <del>, <ins>, <small>) are used inside the <body> tag to format visible prose.

Key Semantic Formatting Elements

  • <strong>: Indicates that its contents have strong importance, seriousness, or urgency (e.g., warnings or crucial terms).
  • <em>: Marks text that has stress emphasis, changing the verbal nuance of a sentence.
  • <mark>: Represents text highlighted for reference or notation purposes.
  • <del> and <ins>: Represent deleted and inserted content, often used in document revisions and pricing discounts.
  • <sub> and <sup>: Render subscript (H2O) and superscript (x2 or 1st).
  • <small>: Denotes side-comments and small print, such as copyright and legal disclaimers.
  • <abbr>: Defines an abbreviation or acronym with an optional title attribute for its expansion.
  • <blockquote> and <q>: Represent extended section quotes and inline short quotes.
  • <code>, <kbd>, and <pre>: Format computer code, user keyboard input, and preformatted whitespace text.

Syntax

HTML 
<p>This is <strong>crucial</strong> and <em>emphasized</em> text.</p>
<p>Sale Price: <del>$99</del> <ins>$49</ins></p>
<p>Water formula is H<sub>2</sub>O and Einstein wrote E = mc<sup>2</sup>.</p>
<p>Press <kbd>Ctrl</kbd> + <kbd>C</kbd> to copy.</p>

Code Example

HTML 
<article>
    <h2>Product Announcement</h2>
    <p>Our new framework is <strong>officially released</strong>!</p>
    <p>Special launch price: <del>$120</del> <mark>$59</mark> for the <abbr title="First Edition">FE</abbr>.</p>
    <blockquote cite="https://example.com/quote">
        "Simplicity is the soul of efficiency."
    </blockquote>
    <p>To install, run <code>npm install my-app</code> in your terminal.</p>
    <p><small>&copy; 2026 Developer Corp. All rights reserved.</small></p>
</article>

Explanation of the Code

  • <strong> clearly highlights "officially released" as the most vital information in the sentence.
  • <del> strikes through the outdated price, and <mark> calls visual and semantic attention to the new price.
  • <abbr title="First Edition"> provides accessibility tools and desktop hover tooltips with the full expansion.
  • <blockquote> creates an indented quotation block with optional citation source tracking via the cite attribute.
  • <code> renders the installation command in a monospace font for visual clarity and code semantics.

Common Mistakes

❌
Using <b> and <i> instead of <strong> and <em>

<b> and <i> are purely stylistic elements from early HTML. They do not convey semantic weight or verbal emphasis to assistive devices like screen readers. Always prefer <strong> for importance and <em> for stress emphasis.

❌
Nesting block elements inside inline formatting tags

Never place block-level elements like <div> or <p> inside inline formatting tags like <strong> or <em>.
