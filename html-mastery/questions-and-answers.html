52. Questions and Answers

Test your knowledge with these common HTML interview questions.

What does HTML stand for?

HyperText Markup Language.

What is the difference between a tag and an element?

A tag is markup such as <p>. An element includes the opening tag, content and closing tag, such as <p>Hello</p>.

What is an attribute?

An attribute provides additional information or configuration for an element, such as href, src, alt, or class.

What is the purpose of DOCTYPE?

It tells the browser to use modern HTML parsing behavior.

What is the difference between head and body?

The head contains metadata and resources. The body contains the document's visible content.

Why is alt important?

It provides a text alternative for images and improves accessibility.

What is the difference between ul and ol?

ul creates an unordered list while ol creates an ordered list.

Why is semantic HTML important?

It communicates the meaning and structure of content to browsers, assistive technologies, search engines and developers.

When should you use a button instead of a link?

Use a button for an action and a link for navigation.

What is the difference between id and class?

An id normally identifies one unique element, while a class can be reused across multiple elements.

Why should labels be connected to inputs?

They improve usability and accessibility, especially for screen-reader users.

What is GET?

GET is commonly used to retrieve, search or filter resources, with parameters often represented in the URL.

What is POST?

POST is commonly used to submit data in the request body, often for operations that create or change server-side data.

What is ARIA?

ARIA provides accessibility roles, states and properties for cases where native HTML does not sufficiently express the required semantics or interaction.

What is lazy loading?

Lazy loading allows suitable non-critical resources to be loaded later, often when they approach the viewport.

What is the DOM?

The DOM is the browser's object representation/tree of the HTML document.

What does defer do?

It allows a script to download during HTML parsing and execute after parsing, while preserving order among deferred scripts.
