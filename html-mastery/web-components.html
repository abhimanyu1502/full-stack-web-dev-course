Web Components Intro

Web Components allow you to create your own custom, reusable, encapsulated HTML tags. It's like building your own native HTML element.

👁️ <body> Used under <body> tag
Tag Placement: Custom web component tags are placed in the <body> tag to instantiate custom HTML elements defined via customElements.define().

Code Example

HTML 
<!-- Usage in HTML -->
<user-card></user-card>
JavaScript 
class UserCard extends HTMLElement {

    connectedCallback() {

        this.innerHTML = `
            <article class="card">
                <h2>Abhimanyu</h2>
                <p>Engineering Student</p>
            </article>
        `;

    }

}

// Register the custom element
customElements.define(
    "user-card",
    UserCard
);

Explanation of the Code

  • Custom element names must contain a hyphen (e.g., user-card) to avoid clashing with future standard HTML tags.
  • We define a JavaScript class that extends HTMLElement.
  • connectedCallback() runs when the element is added to the page, setting its internal HTML.
