14. Tables

Tables are used to display tabular data (data organized in rows and columns). They should never be used for page layout.

👁️ <body> Used under <body> tag
Tag Placement: Tabular data tags (<table>, <thead>, <tbody>, <tr>, <th>, <td>) are used under the <body> tag to display data grids.

Code Example

HTML 
<table>

    <caption>
        Student Marks
    </caption>

    <thead>

        <tr>
            <th scope="col">Name</th>
            <th scope="col">Marks</th>
        </tr>

    </thead>

    <tbody>

        <tr>
            <td>Abhimanyu</td>
            <td>95</td>
        </tr>

        <tr>
            <td>Rahul</td>
            <td>90</td>
        </tr>

    </tbody>

</table>

Explanation of the Code

  • <table>: The container for the entire table.
  • <caption>: The title or description of the table (great for accessibility).
  • <thead>, <tbody>, <tfoot>: Used to group the header, body, and footer rows of the table.
  • <tr> (Table Row): Defines a horizontal row.
  • <th> (Table Header): Defines a header cell. It's bold by default. scope="col" tells screen readers this header applies to the whole column.
  • <td> (Table Data): Defines a standard data cell.
