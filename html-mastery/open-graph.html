25. Open Graph

Open Graph (OG) meta tags control how your webpage looks when shared on social media platforms like Facebook, Twitter, LinkedIn, and Discord.

🧠 <head> Used inside <head> tag
Tag Placement: Open Graph protocol tags (<meta property="og:title">, <meta property="og:image">, <meta property="og:description">) belong strictly inside the <head> tag for social media crawlers.

Code Example

HTML 
<meta
    property="og:title"
    content="My Portfolio"
>

<meta
    property="og:description"
    content="My engineering projects"
>

<meta
    property="og:image"
    content="https://example.com/preview.jpg"
>

<meta
    property="og:url"
    content="https://example.com/"
>

Explanation of the Code

  • Without Open Graph tags, social platforms try to guess what image or text to display when your link is shared (often picking the wrong one). OG tags give you exact control over the preview card.
