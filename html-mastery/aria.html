29. ARIA Attributes

ARIA (Accessible Rich Internet Applications) provides accessibility attributes when visual designs rely on icon-only links or graphics without visible text. It allows assistive technologies (like screen readers) to announce meaningful descriptions while ignoring decorative vector assets.

👁️ <body> Used under tag
Tag Placement: ARIA roles (role="dialog", role="alert") and ARIA states (aria-expanded, aria-hidden) are applied directly to interactive tags inside the <body> tag.

Code Example

HTML 
<!-- The screen reader will now correctly announce: "Link, Follow us on X" -->
<a href="https://x.com" aria-label="Follow us on X">
  <!-- Place your fixed SVG or icon span here -->
  <svg class="icon-x" aria-hidden="true" viewBox="0 0 24 24">
    <path d="M18.244 2.25h3.308l-7.227 8.26 8.502 11.24H16.17l-5.214-6.817L4.99 21.75H1.68l7.73-8.835L1.254 2.25H8.08l4.713 6.231zm-1.161 17.52h1.833L7.084 4.126H5.117z"/>
  </svg>
</a>

Explanation of the Code

  • aria-label="Follow us on X": Provides an accessible name for the anchor element. Because the link contains only an icon and no inner text, aria-label ensures screen readers announce: "Link, Follow us on X" instead of reading an unhelpful URL or remaining silent.
  • aria-hidden="true": Hides the decorative <svg> icon from the accessibility tree. This prevents screen readers from attempting to read raw SVG path coordinate strings or internal metadata.
  • class="icon-x": Used for CSS styling (such as sizing, fill color, and hover transitions) without interfering with accessibility attributes.
💡
The Accessible Icon Pattern

Whenever building icon-only buttons or social links: Always place aria-label on the interactive parent container (<a> or <button>), and add aria-hidden="true" to the child <svg> or graphic icon.
