3. HTML Elements

An HTML element is everything from the start tag to the end tag. It's important to understand the difference between a "tag" and an "element".

👁️ <body> Used under <body> tag
Tag Placement: Visual HTML elements (such as paragraphs, buttons, containers, and headings) belong strictly inside the <body> tag. In contrast, document configuration tags belong in <head>.

Syntax

Concept 
<tag>Content</tag>  ➔ This entire block is an Element

Code Example

HTML 
<p>Hello</p>

Explanation of the Code

  • Opening tag: <p>
  • Content: Hello
  • Closing tag: </p>
  • Complete element: <p>Hello</p>

Note: Some HTML elements have no content and no closing tag. These are called empty elements or self-closing elements. For example, <br> (line break) or <img> (image).
