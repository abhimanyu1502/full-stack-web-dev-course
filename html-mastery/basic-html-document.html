2. Basic HTML Document

Every HTML file needs a specific skeleton to work correctly. This skeleton tells the web browser how to process and display the content.

🌐 <head> & <body> Document Skeleton: <head> & <body>
Tag Placement: The <head> tag holds machine-readable setup and metadata (title, scripts, styles), while the <body> tag holds all visual, interactive content displayed in the browser window.

Syntax

HTML 
<!DOCTYPE html>
<html>
    <head>
        <!-- Settings and metadata go here -->
    </head>
    <body>
        <!-- Visible content goes here -->
    </body>
</html>

Code Example

HTML 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1.0"
    >

    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>
        This is my first webpage.
    </p>

</body>

</html>

Explanation of the VSCode Boilerplate

When you type ! and press Tab in VSCode, it generates this standard boilerplate. Here is exactly what each line does under the hood:

  • <!DOCTYPE html>: Historically, HTML had many confusing versions. This specific tag was introduced in HTML5 as a simple switch to tell the browser: "Use the most modern standards." Without this, browsers fall back into a legacy "Quirks Mode" which breaks modern CSS layouts.
  • <html lang="en">: This is the root element that wraps everything. The lang="en" attribute is critical. It tells screen readers (used by visually impaired users) to pronounce words using English rules. It also helps search engines and translation tools know what language the page is written in.
  • <head>: The brain of the document. Absolutely nothing inside the <head> tag is visible on the actual web page. It strictly contains configuration, styles, scripts, and metadata for the browser and search engines.
  • <meta charset="UTF-8">: Character encoding translates computer bytes into human letters. UTF-8 is the universal standard that supports almost every character in the world, including complex symbols and emojis (😎). Without this, non-standard characters would render as messy symbols (like ).
  • <meta name="viewport" content="...">: The absolute secret to Responsive Design. Before smartphones, websites were built for huge desktop screens. When mobile devices render a page without this tag, they "shrink" the entire desktop site to fit the small screen, making it unreadable. This tag forces the browser to set the width of the page to the physical width of the device (width=device-width) and not zoom out by default (initial-scale=1.0).
  • <title>: This is what appears in the browser tab. It is also the massive blue link that users click on when your page shows up in Google Search results. It is the most important tag for basic SEO.
  • <body>: The canvas. Everything inside the <body> is what the user actually sees and interacts with. Paragraphs, images, links, forms, and videos all go here.
⚠️
Common Mistake

Never put visible content like headings or paragraphs inside the <head> section. Visible content only goes inside the <body>.
