1. Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard language used to create web pages.

HTML exists to tell the browser what each piece of content means and how the page is structured. Think of a webpage like a building. HTML provides the basic structure (the walls, floors, and rooms), CSS provides the presentation (paint, decorations), and JavaScript provides the behavior (electricity, plumbing).

Even if you use modern frameworks like React, Vue, or Angular, they all ultimately generate HTML for the browser to understand. Learning HTML properly is the foundation of all web development.

🌐 <head> & <body> Structure: <head> & <body>
Tag Placement: In HTML documents, tags are divided into two primary zones: <head> tags (e.g. <title>, <meta>, <link>) configure invisible metadata, while <body> tags (e.g. <h1>, <p>, <div>) contain all visible content rendered to the user.

Syntax

HTML is a markup language, meaning it uses "tags" to wrap content and give it meaning. A basic element looks like this:

HTML 
<tagname>Content goes here...</tagname>

Code Example

HTML 
<h1>Hello World</h1>
<p>This is my first webpage.</p>

Explanation of the Code

  • <h1> is an opening tag that defines a large heading. The text "Hello World" is the content.
  • </h1> closes the heading element. The forward slash / indicates it is a closing tag.
  • <p> defines a paragraph of text.
  • The browser reads these tags and translates them into a visual representation for the user.
