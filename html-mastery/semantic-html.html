13. Semantic HTML

Semantic HTML introduces tags that describe their meaning to both the browser and the developer. Instead of using <div> for every section, you use tags that explain what the content is.

👁️ <body> Used under tag
Tag Placement: Semantic landmark tags (<header>, <nav>, <main>, <article>, <section>, <aside>, <footer>) belong inside the <body> tag. Note that the visual <header> tag is inside <body> and is completely different from the document <head> tag.

Syntax

Concept 
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>

Code Example

HTML 
<header>
    <h1>My Blog</h1>

    <nav>
        <a href="/">Home</a>
        <a href="/about">About</a>
    </nav>
</header>

<main>

    <section>

        <h2>Latest Articles</h2>

        <article>

            <h3>Learning HTML</h3>

            <p>
                HTML provides structure and meaning
                to web pages.
            </p>

        </article>

    </section>

    <aside>
        Related content
    </aside>

</main>

<footer>
    Copyright 2026
</footer>

Explanation of the Code

  • <header>: Introductory content, typically containing the logo and main heading.
  • <nav>: A section containing navigation links.
  • <main>: The dominant content of the document. There should only be one main element per page.
  • <section>: A thematic grouping of content, usually with a heading.
  • <article>: A self-contained piece of content that could be distributed independently (like a blog post or news story).
  • <aside>: Content indirectly related to the main content (like a sidebar, ads, or related links).
  • <footer>: The bottom section containing copyright data, links, or contact info.
✅
Best Practice

Semantic HTML is better than using only div elements because it improves accessibility (screen readers rely on semantics to navigate) and improves SEO (search engines understand your page structure better).
