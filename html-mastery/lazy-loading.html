32. Lazy Loading

Lazy loading defers the loading of images (or iframes) that are off-screen until the user scrolls near them.

👁️ <body> Used under tag
Tag Placement: The loading="lazy" attribute belongs on <img> and <iframe> elements inside the <body> tag to defer offscreen asset downloads.

Code Example

HTML 
<img
    src="heavy-image.jpg"
    loading="lazy"
    alt="Example"
>

Explanation of the Code

  • loading="lazy": The browser will wait to download this image until it is needed.
  • loading="eager": (Default) The browser downloads the image immediately.
⚠️
Warning

Do NOT lazy load images that are "above the fold" (visible on the screen immediately when the page loads, like a hero image). This will actually slow down the perceived performance of your site.
