# Guide: Generating Word Documents with Python

This guide explains how to generate a Microsoft Word (`.docx`) file from Python code, similar to the `sihdocument.py` script, and how to execute it.

## 1. Prerequisites

To create Word documents using Python, you need the `python-docx` library. It allows you to programmatically create, modify, and format Word documents.

**Installation:**
You need a `requirements.txt` file containing the library name:
```text
python-docx
```

Then, you install it via the terminal or command prompt:
```bash
pip install -r requirements.txt
```
*(Alternatively, you can just run `pip install python-docx`)*

## 2. The Python Code Structure

The process of creating a document in Python using `python-docx` usually follows these steps:

### A. Importing the Library
You begin by importing the necessary components from `docx`:
```python
from docx import Document
from docx.shared import Inches, Pt, RGBColor
```

### B. Initializing the Document
Create a new, blank document object:
```python
doc = Document()
```

### C. Adding Content (Headings, Paragraphs, Tables)
You can then add content incrementally to your document:
```python
# Add a heading
doc.add_heading('1. Executive summary', level=1)

# Add a standard paragraph
doc.add_paragraph('This is a simple text paragraph.')

# Add a table
table = doc.add_table(rows=1, cols=2)
hdr_cells = table.rows[0].cells
hdr_cells[0].text = 'Item'
hdr_cells[1].text = 'Target'
```

### D. Saving the Document
Once all content is added, you must specify the file path and save the document to your disk:
```python
import os

# Save in the current directory as "output.docx"
output_path = os.path.join(os.getcwd(), 'output.docx')
doc.save(output_path)
print(f"Document saved successfully at: {output_path}")
```

## 3. Common Pitfalls & Fixes (What we fixed in `sihdocument.py`)

Sometimes, Python scripts generated by AI might include shell commands wrapped around them (like `bash -lc cat ...`). 
Python **cannot run bash syntax natively**. 

**How to fix those errors:**
1. **Remove Shell Syntax**: Delete lines like `bash -lc cat > ...` at the top, and `PY`, `ls -lh ...` at the bottom. The file must strictly contain Python code.
2. **Fix Output Paths**: Avoid Linux-specific absolute paths like `/mnt/data/output.docx` on Windows. Use `os.path.join(os.getcwd(), 'filename.docx')` to save it locally where you run the script.
3. **Missing Assets**: If the code tries to add a picture (`doc.add_picture('image.png')`) that you don't have on your computer, the script will crash. Comment out those lines using `#` or provide a valid image path.

## 4. How to Execute the Script

Once your Python script is ready and free of shell-syntax errors, you can run it from the command line:

1. **Open your Terminal** (or Command Prompt / PowerShell).
2. **Navigate** to the folder containing your script using `cd`.
3. **Run the script** using the `python` command followed by the filename:
   ```bash
   python sihdocument.py
   ```
4. If successful, it won't show any errors (and it might print the file path if you added a print statement).
5. Open your file explorer, and you will see your new `.docx` file!
